# Amitys Pet — site (EN)

One-page site for Amitys Happy Pet: plant-based cassava cat litter, cassava + protein meal toppers for dogs, and private label for distributors.

Static HTML, CSS and vanilla JavaScript, with no build step. Open `index.html` or serve the folder.

- **Instagram gallery:** updates on its own from the Behold JSON feed in `data-feed` on `section#instagram` (free plan: the 6 newest posts, shown before the fixed posts).
- **Quote form:** opens Erica's WhatsApp (+55 11 93390-5044), with the request already written.
